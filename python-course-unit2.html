面向对象编程

本单元将带你深入探索Python面向对象编程的核心概念，包括类与对象、继承与多态、魔术方法、设计模式和高级特性。

2.1 类与对象基础 2.2 继承与多态 2.3 魔术方法与运算符重载 2.4 设计模式入门 2.5 高级特性

🏗️ 2.1 类与对象基础

面向对象编程（OOP）是一种程序设计范式，将程序中的数据和操作数据的方法封装在一起形成"对象"。类是对象的蓝图，定义了对象的属性和方法。本节详细介绍类的定义、对象的创建以及self参数。

🎯 学习目标

  • 理解类和对象的概念及其关系
  • 掌握类的定义和对象的创建方法
  • 理解self参数的作用和使用方式
  • 掌握构造函数__init__的使用
  • 区分实例属性和类属性的区别

2.1.1 类的定义与组成

类是创建对象的蓝图，描述了对象的共同特征和行为。使用class关键字定义类，由属性（数据）和方法（函数）组成。

🐍 类的定义与组成

2.1.2 self参数详解

self参数指向对象实例本身，调用方法时Python自动传递。self允许方法访问和修改对象的属性，使不同对象能独立维护状态。

🐍 self参数详解

2.1.3 构造函数__init__详解

__init__是特殊方法，创建实例时自动调用。用于初始化对象属性，构造函数可接受参数进行参数验证。

🐍 构造函数详解

2.1.4 实例属性与类属性

实例属性绑定到特定对象，类属性被所有实例共享。修改类属性影响所有实例，修改实例属性只影响当前对象。

💡 难点提示

属性访问优先级：当实例属性和类属性同名时，实例属性会覆盖类属性，但不修改类属性本身。

🐍 实例属性与类属性

🔄 2.2 继承与多态

继承允许创建新类（子类）继承现有类（父类）的属性和方法。多态允许不同类的对象对同一消息做出不同响应。

🎯 学习目标

  • 理解继承的概念和作用
  • 掌握单继承和多继承的实现方式
  • 学会使用super()函数调用父类方法
  • 理解多态的概念并能够实现
  • 掌握isinstance和issubclass的使用

2.2.1 单继承与多继承

单继承每个子类只有一个父类，多继承一个子类可有多个父类。Python支持多继承，需注意方法解析顺序（MRO）。

🐍 单继承与多继承

2.2.2 super()函数的使用

super()返回父类代理对象，确保正确调用MRO中的下一个类。避免在多继承中重复调用父类构造函数。

🐍 super()函数使用

2.2.3 方法重写与多态

方法重写是子类重新定义父类方法。多态使不同类对象可响应相同消息，Python使用Duck Typing实现多态。

🐍 方法重写与多态

2.2.4 isinstance和issubclass

isinstance()检查对象是否是类的实例，issubclass()检查类是否是另一个类的子类。

🐍 isinstance和issubclass

✨ 2.3 魔术方法与运算符重载

魔术方法是以双下划线开头和结尾的特殊方法，允许自定义类的行为使其使用内置操作符和函数。

🎯 学习目标

  • 理解魔术方法的概念和作用
  • 掌握__str__和__repr__的区别和使用
  • 学会实现迭代器协议（__iter__、__next__）
  • 掌握运算符重载的实现方法
  • 理解上下文管理器的实现

2.3.1 __str__和__repr__

__str__用于用户友好的字符串表示，__repr__用于开发者友好的字符串表示。

🐍 __str__和__repr__

2.3.2 __len__和__iter__迭代器协议

__len__使对象支持len()函数，__iter__和__next__实现迭代器协议。

🐍 __len__和__iter__

2.3.3 __getitem__和__setitem__

__getitem__和__setitem__允许对象使用索引语法进行访问，就像列表和字典一样。

🐍 __getitem__和__setitem__

2.3.4 运算符重载

运算符重载让自定义类支持+、-、*、/等运算符的操作。

🐍 运算符重载

2.3.5 上下文管理器__enter__和__exit__

上下文管理器通过with语句使用，__enter__初始化资源，__exit__清理资源。

🐍 上下文管理器

2.3.6 综合示例：智能数组类

融合所有魔术方法的完整实现，展示如何创建功能强大且易用的自定义数据结构。

🐍 智能数组类

🎨 2.4 设计模式入门

设计模式是解决常见问题的最佳实践。本节介绍四种常用设计模式：单例模式、工厂模式、观察者模式和策略模式。

🎯 学习目标

  • 理解设计模式的概念和作用
  • 掌握单例模式的多种实现方式
  • 理解工厂模式的核心思想
  • 学会使用观察者模式实现事件系统
  • 掌握策略模式解耦算法

2.4.1 单例模式

单例模式确保一个类只有一个实例，应用于配置管理器、数据库连接池、日志系统等场景。

🐍 单例模式

2.4.2 工厂模式

工厂模式将对象的创建与使用分离，通过工厂类统一创建不同类型的对象。

🐍 工厂模式

2.4.3 观察者模式

观察者模式定义对象之间的一对多依赖关系，当对象状态改变时，所有依赖者自动收到通知。

🐍 观察者模式

2.4.4 策略模式

策略模式定义一系列算法并封装起来，使它们可以相互替换。

🐍 策略模式

🚀 2.5 高级特性

本节介绍Python面向对象编程的高级特性，包括装饰器、@property、类方法与静态方法、抽象基类和元类。

🎯 学习目标

  • 理解装饰器的基本概念和使用方法
  • 掌握@property装饰器实现属性访问控制
  • 区分类方法和静态方法的区别
  • 学会使用抽象基类定义接口
  • 理解元类的概念和作用

2.5.1 装饰器基础

装饰器是修改函数或类行为的强大工具，使用@语法糖应用，允许在不修改原函数的情况下添加新功能。

🐍 装饰器基础

2.5.2 @property装饰器

@property允许将方法当作属性访问，实现属性的 getter、setter 和 deleter 功能，同时保持数据封装。

🐍 @property装饰器

2.5.3 类方法与静态方法

类方法通过@classmethod修饰，接收类本身作为第一个参数；静态方法通过@staticmethod修饰，不需要self或cls参数。

🐍 类方法与静态方法

2.5.4 抽象基类（ABC）

抽象基类（Abstract Base Class）用于定义接口，子类必须实现抽象方法才能实例化。

🐍 抽象基类

2.5.5 元类概念入门

元类是创建类的类。在Python中，默认的元类是type。元类允许我们控制类的创建过程，实现类的注册、验证等功能。

🐍 元类概念入门
