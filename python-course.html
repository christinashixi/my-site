Python基础语法（变量、数据类型、运算符）

掌握Python的核心数据类型

本节课深入讲解Python的基础语法，包括变量的定义与使用、6种基本数据类型（整数、浮点数、字符串、布尔值、列表、元组）、以及各种运算符（算术、比较、逻辑、赋值运算符）的使用方法和优先级。

Python是一种动态类型语言，不需要显式声明变量类型，解释器会自动推断。这一特性使Python代码更加简洁灵活，但也需要开发者注意类型转换和类型安全。

📋 学习要点
变量定义整数int浮点数float字符串str布尔值bool类型转换运算符
⚠️ 学习难点

字符串的格式化是初学者容易混淆的地方。Python提供了多种字符串格式化方式：%格式化、str.format()、f-string（推荐）。f-string是Python 3.6+引入的新特性，语法最为简洁直观。

data_types.py - Python数据类型详解
# ============================================ # Python数据类型与变量 # 文件名: data_types.py # 演示Python中的基本数据类型和使用方法 # ============================================ # ---------- 1. 整数类型 (int) ---------- # 用于表示没有小数部分的数值 student_count = 45 # 学生数量 page_number = 100 # 页码 negative_temp = -10 # 负温度 print("===== 整数类型 =====") print(f"学生总数: {student_count}") print(f"页码: {page_number}, 类型: {type(page_number)}") # ---------- 2. 浮点数类型 (float) ---------- # 用于表示带小数部分的数值 price = 99.99 # 商品价格 pi = 3.14159 # 圆周率 temperature = 36.6 # 体温 print("\n===== 浮点数类型 =====") print(f"商品价格: ¥{price}") print(f"圆周率π: {pi}") print(f"体温: {temperature}°C") # ---------- 3. 字符串类型 (str) ---------- # 用于表示文本数据，使用引号包围 name = "张三" # 双引号 message = '你好，Python!' # 单引号 print("\n===== 字符串类型 =====") print(f"姓名: {name}") print(f"消息: {message}") # ---------- 4. 布尔类型 (bool) ---------- # 只有两个值：True（真）和 False（假） is_student = True # 是学生 has_passed = False # 未通过 print("\n===== 布尔类型 =====") print(f"是否是学生: {is_student}") print(f"是否通过: {has_passed}") # ---------- 5. 类型转换 ---------- # 将一种类型转换为另一种类型 int_to_str = str(123) # 整数转字符串 -> "123" str_to_int = int("456") # 字符串转整数 -> 456 float_to_int = int(3.14) # 浮点数转整数 -> 3（截断） print("\n===== 类型转换 =====") print(f"str(123) = {int_to_str}") print(f"int('456') = {str_to_int}") print(f"int(3.14) = {float_to_int}") # ---------- 6. 运算符示例 ---------- print("\n===== 运算符 =====") a, b = 10, 3 print(f"{a} + {b} = {a + b}") # 加法: 13 print(f"{a} - {b} = {a - b}") # 减法: 7 print(f"{a} * {b} = {a * b}") # 乘法: 30 print(f"{a} / {b} = {a / b}") # 除法: 3.33... print(f"{a} // {b} = {a // b}") # 整除: 3 print(f"{a} % {b} = {a % b}") # 取余: 1 print(f"{a} ** {b} = {a ** b}") # 幂运算: 1000 # 比较运算符 print(f"\n{a} > {b}: {a > b}") # True print(f"{a} == {b}: {a == b}") # False print(f"{a} != {b}: {a != b}") # True # 逻辑运算符 x, y = True, False print(f"\nx and y: {x and y}") # False print(f"x or y: {x or y}") # True print(f"not x: {not x}") # False

控制流程（条件语句、循环结构）

让程序具有判断和重复执行能力

控制流程是程序的核心骨架，让计算机能够根据不同条件做出决策，或者重复执行特定任务。本节课涵盖if-elif-else条件判断语句、for循环、while循环、break和continue控制语句，以及列表推导式等高级用法。

📋 学习要点
if-elif-elsefor循环while循环break/continuerange函数列表推导式
⚠️ 学习难点

循环嵌套和列表推导式是本节的难点。循环嵌套容易导致代码复杂度增加，建议控制在3层以内。列表推导式虽然简洁，但过度使用会影响可读性，应根据场景选择是否使用。

control_flow.py - 条件判断与循环
# ============================================ # Python控制流程 # 文件名: control_flow.py # 演示条件判断和循环结构的用法 # ============================================ # ---------- 1. 条件判断语句 ---------- print("===== 条件判断 =====") # 单分支：只有if age = 20 if age >= 18: print("你已经成年了！") # 双分支：if-else score = 85 if score >= 60: print("恭喜你，及格了！") else: print("很遗憾，你没有及格。") # 多分支：if-elif-else grade = 78 if grade >= 90: print("成绩等级: A（优秀）") elif grade >= 80: print("成绩等级: B（良好）") elif grade >= 70: print("成绩等级: C（中等）") elif grade >= 60: print("成绩等级: D（及格）") else: print("成绩等级: F（不及格）") # ---------- 2. for循环 ---------- print("\n===== for循环 =====") # 使用range()生成数字序列 print("打印1-10:") for i in range(1, 11): print(i, end=" ") print() # 遍历列表 fruits = ["苹果", "香蕉", "橙子", "葡萄"] print("\n水果列表:") for fruit in fruits: print(f"- {fruit}") # 使用enumerate获取索引 print("\n带索引的遍历:") for index, fruit in enumerate(fruits, 1): print(f"{index}. {fruit}") # ---------- 3. while循环 ---------- print("\n===== while循环 =====") # 基础while循环 count = 1 while count <= 5: print(f"计数: {count}") count += 1 # ---------- 4. 循环控制语句 ---------- print("\n===== break和continue =====") # break：跳出循环 print("使用break（遇到3停止）:") for i in range(1, 6): if i == 3: break print(i, end=" ") print() # continue：跳过本次循环 print("\n使用continue（跳过3）:") for i in range(1, 6): if i == 3: continue print(i, end=" ") print() # ---------- 5. 列表推导式 ---------- print("\n===== 列表推导式 =====") # 基础列表推导式 squares = [x**2 for x in range(1, 6)] print(f"1-5的平方: {squares}") # 带条件的列表推导式 even_squares = [x**2 for x in range(1, 11) if x % 2 == 0] print(f"偶数的平方: {even_squares}") # ---------- 6. 综合实例：成绩统计 ---------- print("\n===== 综合实例：成绩统计 =====") scores = [85, 92, 78, 96, 65, 88, 73, 90, 82, 70] # 统计各类成绩人数 excellent = sum(1 for s in scores if s >= 90) good = sum(1 for s in scores if 80 <= s < 90) pass_score = sum(1 for s in scores if 60 <= s < 80) fail = sum(1 for s in scores if s < 60) print(f"成绩列表: {scores}") print(f"优秀(≥90): {excellent}人") print(f"良好(80-89): {good}人") print(f"及格(60-79): {pass_score}人") print(f"不及格(<60): {fail}人") print(f"平均分: {sum(scores)/len(scores):.1f}")

函数与模块（参数传递、作用域、常用模块）

代码复用和组织

函数是组织代码的基本单元，可以提高代码的可重用性和可维护性。本节课涵盖函数的定义与调用、参数类型（位置参数、默认参数、关键字参数、*args/**kwargs）、返回值、作用域、以及Python标准库常用模块的使用。

📋 学习要点
def关键字参数类型返回值作用域lambda模块导入
⚠️ 学习难点

*args和**kwargs是函数参数中的难点。*args用于接收任意数量的位置参数（以元组形式），**kwargs用于接收任意数量的关键字参数（以字典形式）。理解这两个概念后，你将能够编写灵活度极高的函数。

functions.py - 函数定义与使用
# ============================================ # Python函数 # 文件名: functions.py # 演示函数的定义、参数类型和返回值 # ============================================ # ---------- 1. 基本函数定义 ---------- print("===== 基本函数 =====") def greet(): """无参数的简单问候函数""" print("Hello! 欢迎学习Python!") def greet_user(name): """带单个参数的问候函数""" print(f"你好，{name}！今天学习顺利吗？") def greet_with_title(name, title="同学"): """带默认参数的函数""" print(f"你好，{title}{name}！") greet() greet_user("小明") greet_with_title("张三") # 使用默认title greet_with_title("李四", "老师") # 覆盖默认title # ---------- 2. 参数类型详解 ---------- print("\n===== 参数类型 =====") # 位置参数：按顺序传递 def student_info(name, age, major): """位置参数示例""" print(f"姓名: {name}, 年龄: {age}, 专业: {major}") student_info("王芳", 20, "计算机") # 关键字参数：按名称传递 student_info(age=19, major="数学", name="赵六") # *args：可变数量的位置参数 def sum_scores(*args): """计算任意数量成绩的总分和平均分""" total = sum(args) average = total / len(args) if args else 0 return total, average total, avg = sum_scores(90, 85, 92, 88) print(f"\n总分: {total}, 平均分: {avg:.1f}") # **kwargs：可变数量的关键字参数 def print_student_info(**kwargs): """打印学生信息（接受任意关键字参数）""" print("\n学生信息:") for key, value in kwargs.items(): print(f" {key}: {value}") print_student_info(name="孙八", age=20, major="化学", score=95) # ---------- 3. 返回值 ---------- print("\n===== 返回值 =====") def calculate_bmi(height, weight): """计算BMI指数并返回结果""" bmi = weight / (height ** 2) if bmi < 18.5: status = "偏瘦" elif bmi < 24: status = "正常" elif bmi < 28: status = "偏胖" else: status = "肥胖" return bmi, status bmi_value, status = calculate_bmi(1.75, 68) print(f"BMI: {bmi_value:.2f}, 状态: {status}") # ---------- 4. lambda函数 ---------- print("\n===== lambda函数 =====") square = lambda x: x ** 2 print(f"平方运算: square(5) = {square(5)}") # lambda配合内置函数使用 students = [ {"name": "张三", "score": 92}, {"name": "李四", "score": 85}, {"name": "王五", "score": 96} ] # 按成绩排序 students_sorted = sorted(students, key=lambda x: x["score"], reverse=True) print("\n按成绩排序（降序）:") for s in students_sorted: print(f" {s['name']}: {s['score']}")

数据结构进阶（列表、元组、集合、字典操作）

Python核心数据结构详解

Python内置了四种核心数据结构：列表（List）、元组（Tuple）、集合（Set）、字典（Dictionary）。每种数据结构都有其独特的特性和适用场景。本节课深入讲解这四种数据结构的创建、访问、修改、遍历方法。

data_structures.py - Python数据结构
# ============================================ # Python数据结构详解 # 文件名: data_structures.py # 演示列表、元组、集合、字典的用法 # ============================================ # ---------- 1. 列表（List） ---------- print("===== 列表（List） =====") fruits = ["苹果", "香蕉", "橙子", "葡萄"] numbers = list(range(1, 6)) print(f"水果列表: {fruits}") print(f"数字列表: {numbers}") # 列表索引和切片 print(f"\n第一个水果: {fruits[0]}") print(f"最后一个水果: {fruits[-1]}") print(f"前两个: {fruits[:2]}") # 列表操作 fruits.append("草莓") print(f"\n添加后: {fruits}") fruits.insert(1, "蓝莓") print(f"插入后: {fruits}") fruits.remove("香蕉") print(f"删除后: {fruits}") popped = fruits.pop() print(f"弹出: {popped}, 剩余: {fruits}") # ---------- 2. 元组（Tuple） ---------- print("\n===== 元组（Tuple） =====") coordinates = (100, 200) point = 10, 20, 30 print(f"坐标: {coordinates}") print(f"点: {point}") # 元组解包 x, y = coordinates print(f"解包: x={x}, y={y}") # 多变量同时赋值 a, b = 5, 10 a, b = b, a print(f"交换后: a={a}, b={b}") # ---------- 3. 集合（Set） ---------- print("\n===== 集合（Set） =====") math_students = {"张三", "李四", "王五", "赵六"} english_students = {"李四", "王五", "孙七", "周八"} print(f"数学学生: {math_students}") print(f"英语学生: {english_students}") print(f"\n交集 (两门课都选): {math_students & english_students}") print(f"并集 (至少选一门): {math_students | english_students}") print(f"差集 (只选数学): {math_students - english_students}") # ---------- 4. 字典（Dictionary） ---------- print("\n===== 字典（Dictionary） =====") student = { "name": "小明", "age": 20, "major": "计算机科学与技术", "scores": {"数学": 92, "英语": 88, "编程": 95} } print(f"学生信息: {student}") print(f"姓名: {student['name']}") print(f"数学成绩: {student['scores']['数学']}") student["gpa"] = 3.8 student["age"] = 21 print(f"\n更新后: {student}") print("\n遍历学生信息:") for key, value in student.items(): print(f" {key}: {value}") # ---------- 5. 综合实例 ---------- print("\n===== 综合实例：学生成绩管理系统 =====") students = { "001": {"name": "张三", "scores": [85, 92, 88]}, "002": {"name": "李四", "scores": [78, 85, 82]}, "003": {"name": "王五", "scores": [95, 90, 98]}, } print("学生成绩:") for sid, info in students.items(): avg = sum(info["scores"]) / len(info["scores"]) info["average"] = round(avg, 1) print(f" {sid} {info['name']}: 平均 {info['average']}") best = max(students.items(), key=lambda x: x[1]["average"]) print(f"\n最高分学生: {best[1]['name']} ({best[1]['average']}分)")
